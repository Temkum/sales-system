# Sales System

## Tech Stack

-   Frontend:
    -   Framework: Bootstrap 5
    -   HTTP Client: Axios
-   Backend:
    -   Framework: Laravel 10.x
    -   ORM: Laravel Eloquent
    -   Database: MySQL
    -   Authentication: Laravel Sanctum
    -   Routing: Laravel Routing
    -   Cache: Laravel Cache
    -   Queue: Laravel Queue
-   Database:
    -   Database System: MySQL
    -   Database Library: Laravel Database
